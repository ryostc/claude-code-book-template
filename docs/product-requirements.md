# プロダクト要求定義書

## プロダクトビジョンと目的

既存のタスク管理ツールは記録が面倒で続かない。本ツールはCLIに溶け込むことで自然に実績を蓄積し、見積もり精度を改善する唯一のツールを目指す。

---

## ターゲットユーザー

### プライマリユーザー
- 「見積もりがいつも外れる」と感じている個人開発者
- 環境: Windows（WSL2）上のVS Codeターミナルを日常的に使う開発者

### ユーザーの課題・ニーズ

| 課題 | ニーズ |
|---|---|
| GUIツールに切り替えるのが面倒 | ターミナルから離れずタスクを管理したい |
| 見積もりがいつも甘い | 過去の実績から正確な見積もりを立てたい |
| なぜ遅れたか振り返れない | タスク種類別の傾向を把握したい |
| 記録が面倒で続かない | 自然に実績が溜まる仕組みがほしい |

---

## 主要な機能

1. **タスクCRUD** — 追加・一覧・編集・完了・削除
2. **見積もり入力** — タスク作成時に見積もり時間を設定（必須）
3. **タイマー機能** — `start` / `pause` / `done` コマンドで作業時間を自動計測
4. **実績記録** — 完了時に実際の作業時間（中断時間を除く）を記録
5. **統計・振り返り** — 見積もり vs 実績の乖離をタスク種類別に表示
6. **類似タスク提案** — 見積もり入力時に過去の類似タスクの実績を表示

---

## 成功の定義

- `todo start` から `todo done` まで追加コマンドが0で完結する
- 統計表示に必要な最小データ数: 5タスク
- 乖離率の計算式: `(実績時間 - 見積もり時間) / 見積もり時間 × 100`
- 乖離率の改善トレンドをシステムが自動計算して表示する
  - 例: 最初の10タスクの平均乖離率 `+180%` → 直近10タスク `+95%`（改善中）

## ユーザーストーリー

### タスク管理
- 開発者として、タスクをCLIで素早く追加したい（コンテキストを切らずに）
- 開発者として、現在のタスク一覧をターミナルで確認したい
- 開発者として、完了したタスクをアーカイブして一覧をすっきりさせたい
- 開発者として、作成済みのタスクのタイトル・見積もり・タグを編集したい

### 時間トラッキング
- 開発者として、タスク開始時にタイマーを自動スタートしたい
- 開発者として、タスク完了時に実績時間を自動記録したい
- 開発者として、中断・再開をコマンド1つで行いたい（中断時間は除外）

### 振り返り
- 開発者として、見積もり vs 実績の乖離を一覧で確認したい
- 開発者として、タスク種類（バグ修正・新機能など）別の傾向を把握したい
- 開発者として、新しいタスクの見積もり時に類似タスクの過去実績を参照したい

## 受け入れ条件

### タスク管理
- [ ] `todo add "タスク名" --estimate 2h` でタスクが作成される
- [ ] `todo list` でタスク一覧が表示される
- [ ] `todo edit <id>` でタイトル・見積もり・タグを編集できる
- [ ] `todo delete <id>` でタスクが削除される

### タイマー・状態管理
- [ ] `todo start <id>` でタイマーが開始される（見積もりなしのタスクはエラー）
- [ ] 作業中のタスクに `todo start` を再度呼ぶとエラーになる
- [ ] `todo pause` で中断でき、中断時間は実績から除外される
- [ ] `todo done` で作業中・一時停止中のタスクが完了し実績時間が記録される
- [ ] 一時停止中に `todo done` を呼ぶと確認プロンプトが表示される（デフォルトN）

### 統計・振り返り
- [ ] `todo stats` で見積もり vs 実績の統計が表示される
- [ ] 5タスク以上蓄積すると乖離率の傾向が表示される
- [ ] 乖離率の改善トレンドが期間別（3ヶ月前・半年前・1年前・全期間）で表示される
- [ ] データが足りない期間は非表示になり、蓄積されると自動的に表示される

### データ
- [ ] データはローカルの `~/.todo/tasks.db`（SQLite）に保存される
- [ ] 1日1回、その日最初のコマンド実行時に自動バックアップが作成される
- [ ] バックアップは `~/.todo/backups/tasks-YYYY-MM-DD.db` の形式で保存される
- [ ] バックアップは直近30日分を自動保持し、古いものは自動削除される
- [ ] `todo restore <file>` でバックアップから復元できる
- [ ] オフライン・外部サービスなしで完全動作する

## 機能要件

### コマンド一覧

```
todo add <title> --estimate <time> [--tag <tag>]
todo list [--status <status>]
todo edit <id> [--title <title>] [--estimate <time>] [--tag <tag>]
todo start <id>
todo pause
todo done [--note <text>]
todo stats [--tag <tag>] [--period <days>]
todo show <id>
todo delete <id>
todo backup list
todo restore <file>
todo <command> --help
```

### タスクの状態遷移

```
[未着手] --start--> [作業中] --pause--> [一時停止]
                        |                    |
                        +------done----------+
                                |
                            [完了]
```

- `start`: 未着手 → 作業中（見積もりなし・作業中・完了はエラー）
- `pause`: 作業中 → 一時停止
- `done`: 作業中 または 一時停止 → 完了（一時停止中は確認プロンプト）

### 類似タスク提案ロジック（要ブラッシュアップ）

見積もり入力時に表示する「類似タスク」の判定基準は以下を検討中：
- タグが一致するタスクの過去実績
- タイトルの単語が部分一致するタスクの過去実績

### データ保存
- ローカルの `~/.todo/` ディレクトリに保存
- SQLite（`~/.todo/tasks.db`）を使用
- タイムゾーン: JST（UTC+9）固定

## 非機能要件

- **応答速度**: 全コマンド 200ms 以内に応答
- **対応環境**: Windows（WSL2）、Node.js 18以上
- **データ破損対策**: 1日1回自動バックアップ（直近30日分保持）、`todo restore` でワンコマンド復元
- **エラーハンドリング**: 不正な入力・状態遷移違反に対して分かりやすいエラーメッセージを表示
